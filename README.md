# API de Produtos
Execute `composer run setup` para instalar e configurar o projeto.
Inicie com `php artisan serve` e abra `http://127.0.0.1:8000` para usar a tela de produtos.
Use `/api/produtos` para o CRUD e `/api/catalogo-externo` para consultar a DummyJSON.
Para testar, importe a coleção e o ambiente da pasta `postman` no Postman e execute a coleção.
